Data Engineer & Data Analyst
----------------------------------------

I work with real operational data at a food manufacturer in Thailand. I build pipelines that pull data from the ERP and Google Sheets, check it for errors, and turn it into dashboards and tools that teams use every day.

ผมทำงานกับข้อมูลจริงในโรงงานผลิตอาหาร ตั้งแต่ดึงข้อมูลจาก ERP และ Google Sheets ตรวจหาข้อผิดพลาด ไปจนถึงทำ Dashboard และเครื่องมือที่ทีมใช้ทุกวัน

Highlights
* 📦 Stock dashboard that reconciles **100%** with the warehouse team's own summary, by SKU and by day
* 🧾 Purchase-order checker that reads **17 file formats** (Excel, CSV, PDF) from 10+ customers and sends them to the ERP
* 🏭 QC dashboard that turns production defects into **Thai baht** so problems can be ranked by cost
* 🔁 Monthly sales pipeline that is **safe to re-run**, with no duplicates, feeding Looker Studio
* 🛒 Purchase-request form + Kanban board with **approvals in the company chat**
